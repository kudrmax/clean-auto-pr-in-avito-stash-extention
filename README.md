# Clean AutoPR in Avito Stash

Убирает AutoPR из «Pull requests to review» в Stash и показывает их отдельной секцией.

## Установка

1. `chrome://extensions` → включить **Developer mode**.
2. **Load unpacked** → выбрать папку репозитория.
3. Обновить дашборд Stash.

Обновление: `git pull`, ⟳ на карточке расширения.
